# CutKit Teleprompter for Claude Code

CutKit is an iPhone teleprompter that follows your voice while you record. This plugin lets Claude Code write the scripts it reads. Ask for a script, and it's waiting in the app the next time you open it.

The plugin adds the CutKit MCP server (`https://getcutkit.com/mcp`) and one skill that knows the common teleprompter jobs: draft a script, start one from a hook template, grade it, tighten it to a length, and keep the library tidy with labels.

## Install

```
/plugin marketplace add heyramzi/cutkit-plugin
/plugin install cutkit-teleprompter@cutkit
```

Then run `/mcp`, pick `cutkit` and choose Authenticate. Your browser opens getcutkit.com. Sign in with the CutKit account you use on your iPhone and press Allow.

You need the CutKit app on your iPhone and a CutKit account. Get the app at [getcutkit.com](https://getcutkit.com).

## Try

- "Show me my CutKit scripts."
- "Write a 60 second intro for my cold brew video and put it on my teleprompter."
- "Start a script from a question hook about pricing my first client."
- "Check my Launch video intro script and fix what fails."
- "Make the Outreach label blue."

## Access

Only your own script library and creator profile. Your recordings and your voice stay on your phone. Claude asks before it calls a tool that changes or deletes something. See every connected app at [getcutkit.com/app/connect](https://getcutkit.com/app/connect) and disconnect any of them in one tap.
